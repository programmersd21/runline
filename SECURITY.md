# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of Runline seriously. Runline executes local `gh` CLI commands and processes run metadata and logs.

If you discover a security vulnerability:

1. **Do not open a public issue.**
2. Send an email to the repository maintainers or report it privately through GitHub Security Advisories.
3. Include detailed steps to reproduce the vulnerability, including your environment and sample fixtures if applicable.

We will acknowledge receipt within 48 hours and work on a coordinated release and disclosure.
